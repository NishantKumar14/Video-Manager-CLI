# 🎬 Video Manager (CLI)

A simple command-line Python application that allows users to **add**, **list**, **update**, and **delete** video records. All data is saved in a local JSON file (`video.txt`), simulating persistent storage.

---

## 🚀 Features

-   ✅ List all saved videos
-   ➕ Add a new video (name and duration)
-   ✏️ Update an existing video
-   ❌ Delete a video
-   💾 Data is saved automatically in a local file using JSON

---

## 🛠️ Technologies Used

-   **Python 3**
-   **JSON module** (built-in)

## 📦 How to Run

1. **Clone the repository** (or copy the files manually):

```bash
git clone git@github.com:NishantKumar14/Video-Manager-CLI.git
cd Video-Manager-CLI
```

2. **Check python install**:

```bash
python --version
```

3. **Run the program**:

```bash
python main.py # On Window Os
python3 main.py # On linux/Unix Os
```
